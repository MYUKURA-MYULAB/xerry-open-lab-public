# Synthetic cases

**Synthetic material, not real clinical data.** The JSONL file contains four fictional text cases (identifiers `synthetic-001` to `synthetic-004`) and human-authored reference facts to illustrate the evaluator schema. It contains no audio and is not derived from a patient record or any real clinical source.

These examples are protocol fixtures, not a representative dataset. They are too small to support a model-quality claim, and the labels have not undergone independent clinical annotation. The source quotations illustrate exact evidence-span occurrence; the scorer does not assess semantic entailment.

No external dataset is required. A future benchmark release must include provenance, license, annotation guidance, split policy, and review status before it can support research claims.
